# 画布工具本体 · 总导航

**版本：v1.2.0**（P0 汇总：细粒度写 · 磁盘已更新 · 模块库落盘 · 连线全锚点）

## 唯一入口

```text
双击  启动画布工具.bat
```

- **不要**直接双击 / 用浏览器打开 `前端\index.html`（`file://` 下磁盘保存、`/api/state`、部分右键能力会失效）。
- 换端口：`启动画布工具.bat -Port 4186`。
- 启动后浏览器地址形如 `http://127.0.0.1:4173/index.html`（若 4173 被占，启动台会尝试下一端口）。

目录分工：

```text
启动画布工具.bat / launch.ps1   启动链（唯一正式入口）
前端/                           页面与交互（不是双击入口）
后端/                           启动脚本 + canvas_server.py
工作流导出/                      画布数据.json（AI 可读写）
docs/                           说明与汇报（不参与运行）
使用说明.md                      给其他人看的使用文档
```

**产品边界（常显）**：本工具是**设计沟通画布**，**≠** 民诉法云端课堂的**课堂/正式时间线画布**；两套产品勿混。上级项目分区见 `..\readme.md`。
