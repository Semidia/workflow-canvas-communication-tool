# 工作流画布沟通工具：本体目录

## 唯一启动台

请双击本目录中的：

```text
启动画布工具.bat
```

这是本体唯一推荐的启动入口。它会检查运行环境，在 `前端` 目录启动本地 HTTP 服务，并打开：

```text
http://127.0.0.1:4173/index.html
```

关闭启动台窗口，会结束本次启动的本地服务。

如果 4173 端口被其他程序占用，启动台会自动尝试下一个端口。如果检测到占用端口的是已经运行的画布，会提供两个选择：

1. 终止当前画布进程并重新启动。
2. 打开正在运行的画布。

如需临时换端口，可在命令行运行：

```text
启动画布工具.bat -Port 4186
```

## 目录分工

```text
画布工具本体/
├─ 启动画布工具.bat        # 用户双击的唯一启动台
├─ readme.md                # 本文件，负责总导航
├─ 前端/                    # 页面、样式、交互、草图和前端测试
├─ 后端/                    # 本地薄后端（canvas_server.py）+ 启动辅助脚本
└─ 工作流导出/              # 画布数据落盘目录（画布数据.json，供 AI agent 直接读写）
```

- `前端/index.html`：正式编辑器页面。
- `前端/app.js`：画布交互、本地保存和导入导出。
- `前端/styles.css`：页面样式。
- `前端/草图`：早期视觉草图，不是正式入口。
- `前端/tests`：前端自动化验收脚本。
- `后端/启动画布工具.ps1`：被启动台调用的本地服务辅助脚本。
- `后端/canvas_server.py`：本地薄后端，静态文件 + `/api/state` 磁盘读写。
- `工作流导出/画布数据.json`：右键「保存到磁盘」生成的落盘文件，本机 AI agent 可直接 `Read/Edit`。

## 当前产品边界

这是一个本地的设计沟通画布，用来把人与 AI 共同讨论的产品逻辑画清楚。它不是 AI 智能体执行器，不连接具体业务系统、模型 API、账号权限或云端服务。

数据默认保存在当前浏览器本地，不会自动上传到 GitHub 或其他云端。重要版本请使用页面顶部“导出”另存 JSON；含有个人内容的导出文件不要提交到公开仓库，建议放到 `工作流导出` 文件夹或使用 `.workflow.json` 后缀。

为了和 AI 交流，页面各元素都支持右键复制「给 AI 看」的文本快照 / JSON，也能右键「保存到磁盘」写入 `工作流导出/画布数据.json`、或「从磁盘加载」回写画布。详见 `前端/readme.md` 的「和 AI 配合」一节。

## 隐私边界

- 仓库公开的是源码、说明和测试，不包含浏览器里的本地画布草稿。
- 本工具没有账号、云端同步、模型 API 或后台数据库。
- 如果你手动导出工作流 JSON，请先检查内容，再决定是否分享。
