# 前端：设计沟通画布

这是工作流画布沟通工具的编辑器本体。它的用途是把任何开发项目的想法画出来：放节点、写文字、拉线、移动和整理流程，再把结果交给 AI 共同讨论。它不是 AI 智能体执行器，也不连接具体业务系统。

## 打开

请回到上一级目录，双击唯一启动台 `启动画布工具.bat`。它会启动本地 HTTP 服务并打开本页面。

如需手动启动，请在本文件夹启动一个本地 HTTP 服务，再打开：

```text
http://127.0.0.1:4173/index.html
```

## 怎么用

- 左侧“选择”工具：点击或拖动节点。
- 左侧“步骤、判断、开始/结束、材料、提醒”工具：再点击画布空白处放置节点。
- 左侧“文字”工具：双击画布空白处，输入文字后按回车。
- 左侧“连线”工具：先点一个节点，再点另一个节点；也可以拖动节点边缘的小圆点。
- 双击节点文字：修改文字。
- 选中节点后，先点击卡片右上角的缩放图标，再拖动形状对应的控制点调整大小：矩形/材料/文字为四角，菱形/圆形为四个方向，三角形为三个顶点；连接点会保持清楚可见，不同形状会保留最低安全尺寸。
- 选中节点后，可在右侧“节点信息”编辑名称、说明和讨论标记，并查看前置/后续节点。
- 讨论标记有“待讨论、已决定、有疑问、不采用”四种，只表示人与 AI 的沟通情况，不代表系统执行状态。
- 选中节点或连线后按 `Delete`：删除。
- 空白处拖动：移动整个画布。
- 底部 `− / 100% / ＋`：缩放画布。
- 顶部“保存”：保存到当前浏览器；“导出”：导出 JSON 文件；“导入”：读取 JSON 文件。

## 数据放在哪里

默认保存在当前浏览器的本地存储中，不上传到云端。画布发生修改后，工具会等待约 600 毫秒自动保存，并覆盖同一个本机草稿；刷新或关闭页面前也会再补保存一次。顶部“保存”仍可手动立即保存；重要版本请使用“导出”另存一份 JSON，因为自动保存不是历史备份。若本机存储空间不足或被浏览器禁用，状态栏会显示“自动保存失败”，此时应立即导出 JSON。

## 当前范围

当前版本是通用的“设计沟通工具”，不是智能体执行器。它没有连接业务数据、模型 API、账号权限或云端服务；导出的 JSON 是沟通材料，不是正式执行合同。

隐私说明：画布自动保存到当前浏览器本地，不会自动上传。导出的工作流 JSON 可能包含你的个人或项目内容，请勿直接提交到公开仓库；公开仓库已忽略 `工作流导出` 文件夹和 `*.workflow.json` 文件。

本版本按宽屏工作区设计，不专门适配窄屏；窄屏打开时可能按比例缩放或出现局部遮挡。

缩放规则：最小 `1%`，最大 `220%`；点击放大每次增加 `5%`；当前低于 `10%` 时，点击缩小每次减少 `1%`；到边界后保持不变。

## 文件说明

- `index.html`：页面结构。
- `styles.css`：版本五的设计沟通画布视觉样式。
- `app.js`：画布交互和本地数据处理。
- `草图`：之前用于比较方向的静态草图，不是正式编辑器入口。
- `tests\\workflow-canvas-acceptance.mjs`：本体功能和缩放边界检查。

启动台、目录分工和后端边界请看上一级的 `readme.md`。

## 和 AI 配合

画布负责把逻辑表达清楚，AI 负责阅读、提问、复盘和提出修改建议。建议每次讨论都保留一份导出的 JSON 或截图，方便回看当时的设计。
