# 画布工具本体 · 产品架构

> 与民诉法云端课堂**无关**。本文件只描述设计沟通画布。

## 1. 定位

| 项 | 说法 |
|----|------|
| 产品名 | 设计沟通画布 / 工作流画布沟通工具 |
| 用途 | 人与 AI 共同把产品逻辑画清楚、讨论清楚、改清楚 |
| 边界 | 非执行器、非业务系统、非民诉时间线画布、无账号/云/模型 API |
| 形态 | 本地单页应用 + 本地薄后端 |

## 2. 分层

```text
┌─────────────────────────────────────────┐
│  浏览器  前端/  (index + 分模块 JS)      │
│  · 编辑、缩放、历史、模块库、右键 AI 桥  │
│  · localStorage 草稿 (~600ms 自动存)    │
└───────────────┬─────────────────────────┘
                │ HTTP 127.0.0.1
┌───────────────▼─────────────────────────┐
│  后端/ canvas_server.py                 │
│  · 静态服务 前端/（no-store）            │
│  · GET/POST /api/state                  │
└───────────────┬─────────────────────────┘
                │ 原子写
┌───────────────▼─────────────────────────┐
│  工作流导出/画布数据.json                │
│  · AI 可 Read/Edit 的磁盘权威稿         │
└─────────────────────────────────────────┘
```

启动链：`启动画布工具.bat` → `launch.ps1` → `后端/启动画布工具.ps1` → 起服务并开浏览器。

## 3. 前端模块（加载顺序即依赖）

`constants → storage → state → canvas → node → edge → inspector → ai-bridge → modules → marquee → events → app`

| 模块 | 职责 |
|------|------|
| constants | 常量、节点类型、DOM 引用 |
| state / storage | 状态、归一化、localStorage |
| canvas / node / edge | 绘制与交互 |
| inspector | 右侧节点信息（含循环结束条件警告） |
| ai-bridge | 快照、导入导出、/api/state、真相状态与磁盘轮询 |
| modules / marquee | 模块库、框选 |
| app | 装配与入口 |
| events | 事件绑定、脚本自检、启动引导（最后加载） |

## 4. 数据契约（磁盘 / 导出）

```json
{
  "version": 1,
  "activeCanvasId": "…",
  "canvases": [{
    "id": "…",
    "name": "…",
    "category": "…",
    "nodes": [{ "id", "type", "x", "y", "w", "h", "label", "note", "marker", "condition", "exitCondition" }],
    "edges": [{ "id", "from", "to", "branch", "label", "loop", "fromSide", "toSide", "width", "color" }],
    "view": { "zoom", "panX", "panY" }
  }]
}
```

节点 `type`：`rect` | `diamond` | `circle` | `document` | `triangle` | `text`  
讨论 `marker`：`待讨论` | `已决定` | `有疑问` | `不采用`

## 5. 与「民诉时间线画布」对照（防混淆）

| | 设计沟通画布（本工具） | 民诉正式时间线画布 |
|--|----------------------|-------------------|
| 产品 | workflow-canvas-communication-tool | cloud-classroom |
| 数据 | 本机 JSON / 浏览器 | 课堂 store / 云 |
| 节点 | 流程步骤/判断等 | 提交卡/法院记录 |
| 线 | 讨论连线 | 回应/引用/批注契约 |
| 启动 | 启动画布工具.bat :4173 | npm run dev / 上云 |

## 6. 扩展约定

- 运行代码只进 `前端/`、`后端/`；说明进 `使用说明.md` 与 `docs/`。
- 新增启动参数：`启动画布工具.bat` 透传 → `launch.ps1` 与 `后端/启动画布工具.ps1` **三处同步**。
- `.bat` 保持纯 ASCII；中文路径只写在 `.ps1`。
- 真实业务后端若出现：仍放 `后端/` 独立入口，不混入 `前端/`。
